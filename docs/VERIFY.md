# 真机验收清单（接上 adb 后按序执行）

> 构建产物：`app/build/outputs/apk/debug/app-debug.apk`（`pwsh -File build.ps1 assembleDebug`）
> 安装：`adb install -r app\build\outputs\apk\debug\app-debug.apk`
> 全程以**真机**为准（模拟器无法验证保活与续航）。

---

## M0 脚手架

- [ ] `adb install -r` 安装成功，桌面出现「回声」图标（蓝底白色声波）
- [ ] 打开 App：底部出现液态玻璃 Dock，五个项目（记忆 / 收藏 / 待办 / 备忘 / 设置）
- [ ] 依次点击五个 Dock 项，页面正确切换且选中态高亮正确
- [ ] 设置 → 液态玻璃：关闭后 Dock 与卡片变为平面半透明；开启后恢复玻璃质感（**切换应立即生效**）
- [ ] 设置 → 主题：跟随系统 / 浅色 / 深色 三档生效
- [ ] 杀进程重开：设置项（含玻璃开关、主题）**持久化保留**
- [ ] 设置 → 记录时长滑杆：30 秒 ~ 5 分钟可调，数值实时显示（如「3 分钟」「2 分 30 秒」）

## M1 录音引擎（后台聆听 + 环形缓冲 + 回溯）

- [ ] 首次进入点「开启聆听」：弹出麦克风权限与通知权限请求，授予后状态卡变为「正在聆听」并出现常驻通知
- [ ] 说话 10 秒 → 点「回溯记忆」→ 生成一条记忆，能听到刚才说的话
- [ ] **取走即消失**：立刻再点一次「回溯记忆」，返回空态（「最近 X 分钟没有人声被记录」）
- [ ] 静默不说话时点回溯 → 空态提示，且缓冲不被清空
- [ ] 窗口滚动：把窗口设为 1 分钟，说话后静默等待 2 分钟，再点回溯 → 取不到 2 分钟前的声音
- [ ] 锁屏后继续聆听：锁屏 30 分钟，解锁后点回溯 → 能取到锁屏期间最后 X 分钟的人声
- [ ] 常驻通知的「回溯」快捷按钮可用（不打开 App 也能取记忆）
- [ ] 人声灵敏度三档差异可感知（高：轻声也触发；低：需较大声）
- [ ] 内存观察：连续运行 1 小时，`adb shell dumpsys meminfo com.echo.recall.debug` 中 PSS 稳定（无持续增长）

## M2 本地转写

- [ ] 设置 → 本地语音模型：首次下载有进度、可断点续传、可取消
- [ ] 下载完成后断网，回溯一条人声 → 转写文字正常出现（**证明全本地**）
- [ ] 转写速度：5 分钟窗口 ≤ 40 秒（中端机），中文字幕带标点
- [ ] 字幕可点击跳转播放对应片段；时间戳与音频对得上
- [ ] 弱网/无网环境下重复回溯不报错
- [ ] 手动导入模型：选择本地 `model.int8.onnx` 后可用

## M3 云端 LLM

- [ ] 设置 → AI 供应商：8 家全部列出，贴入 API Key 后「验证并拉取模型」成功返回模型列表
- [ ] 至少实测 3 家（推荐 DeepSeek / 智谱 GLM / Kimi）能正常总结与追问
- [ ] 自定义供应商：填入 baseUrl + Key + 模型名后可正常调用
- [ ] 记忆详情 → AI 总结：流式输出，结果缓存；断网时给出明确错误提示
- [ ] 记忆详情 → 追问：多轮对话基于转写文本，回答内容与录音相关
- [ ] 备忘录：一键总结、一键润色可用，润色可预览并可撤销
- [ ] 隐私核查：抓包或看请求日志确认**只上传文字**，不上传音频

## M4 全功能 UI

- [ ] 记忆可收藏（⭐）→ 出现在收藏页；取消收藏后从收藏页消失
- [ ] 未收藏记忆 7 天后自动清理：`adb shell` 手动改系统时间或把条目时间改早后验证（收藏的不受影响）
- [ ] 待办：增 / 改 / 删 / 勾选完成 / 置顶，重启后数据仍在
- [ ] 备忘录：增 / 改 / 删，长文本编辑不卡顿
- [ ] 液态玻璃在所有主要页面表现一致（Dock、卡片、回溯按钮）
- [ ] 深色/浅色下玻璃质感与文字对比度都可接受

## M5 保活与续航

- [ ] 设置 → 后台保活引导：能识别机型品牌并给出对应设置步骤
- [ ] 授权「忽略电池优化」后，锁屏放置 8 小时：`adb shell dumpsys batterystats` 显示服务未中断
- [ ] 过夜 soak：8 小时后点回溯仍正常工作（进程未被杀）
- [ ] 电量报告：记录 1 小时纯聆听的电量下降百分比（目标 < 3%/h），与 `adb shell dumpsys batterystats --charged com.echo.recall.debug` 交叉核对
- [ ] 进程被系统杀掉后：能从常驻通知 / 快捷磁贴一键恢复聆听
- [ ] 重启手机后：打开 App 即恢复聆听（Android 15 起不允许开机自启麦克风服务，属平台限制）
- [ ] 崩溃恢复：手动 `adb shell am crash com.echo.recall.debug` 后服务自动重启
- [ ] Release APK 正常安装运行（`pwsh -File build.ps1 assembleRelease`）
